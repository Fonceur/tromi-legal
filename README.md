# Tromi privacy policy: moved

The Tromi privacy policy is now at https://fonceur.github.io/tromi/privacy.html, with its French translation at https://fonceur.github.io/tromi/privacy-fr.html. One policy covers the Android and the iPhone and iPad apps, and both store listings link to it.

This site, https://fonceur.github.io/tromi-legal/, now only redirects there (`index.html`), so older links keep working. The last copy of the policy kept here, dated October 12, 2026, is in this repository's history.
